# 任务：AgentBell 阶段 2 — 菜单栏常驻（已按 D004 / D005 重写）

> 本文件已重写。上一版基于 D003"Codex 拿不到开始信号"，该结论已被 **D004 推翻**。
> 执行前务必先读 `needs/decisions.md`，那里的决定优先级高于其他所有文档。

**目标**：菜单栏常驻一个图标，一眼看到两个 agent 各自在跑什么、跑了多久，以及最近完成了哪些。开机自动启动。

## 范围

1. **Swift 原生菜单栏 App**：`LSUIElement = true`（不占 Dock），用 `swiftc` 编译并手工组 `.app` bundle，`codesign -s -` 做 ad-hoc 签名。机器上只有 Command Line Tools，**没有完整 Xcode，不要生成 Xcode 工程、不要用 SPM**。

2. **Codex 侧接入"开始"信号**（本轮新增，D004）：
   - 先查清 Codex 0.157 的 hooks 机制：`hooks.json` 的实际位置、格式、事件名（二进制里已确认存在 `SessionStart` / `UserPromptSubmit` / `TurnStarted` / `SessionEnd`）。**先弄清楚再写代码，不要凭猜测配置。**
   - 挂 `SessionStart` 或 `TurnStarted`（按实际语义选），配合既有完成信号算出运行中状态与时长。
   - **`~/.codex/config.toml` 的 `notify` 串联绝对不能动。** Codex Computer Use 依赖它，阶段 1 已验证通过。新的 hooks 与它并存，不是替代。
   - 若 hooks 需要信任机制（有 `--dangerously-bypass-hook-trust` 这个开关），按正规方式登记信任，**不要在安装脚本里使用这个 bypass 开关**。

3. **Claude 侧存活判定**（避免已知坑）：
   - Claude 桌面端在 local agent mode 下是**无 TTY 子进程**，`ps` / `lsof` 看不到。
   - **存活必须跟着 `Claude.app` 判断**（`NSWorkspace.shared.runningApplications`），不能跟终端进程，否则会话会在出现约 6 秒后被误判为已结束。
   - 桌面端可通过环境变量 `CLAUDE_CODE_ENTRYPOINT=claude-desktop` 识别。
   - `UserPromptSubmit` hook 上一轮已装上，保留。**仍然不挂 `PreToolUse` / `PostToolUse`。**

4. **状态来源**：监听 `~/.agentbell/logs/events.jsonl` 新增行，轮询文件大小变化即可（1 秒一次），不引第三方库。

5. **菜单内容**：运行中的会话（来源 + 项目目录名 + 已运行时长）、最近完成若干条（来源 + 项目 + 完成时刻 + 最后回复摘要）、退出项。

6. **开机自启**：`~/Library/LaunchAgents/` 下的 plist，`RunAtLoad`，由 `install.sh` / `uninstall.sh` 负责装卸。

## 必要约束

- **不要改通知与提示音的发送方式**（D001）。通知仍由事件脚本发出，App 只做状态显示。阶段 1 已验证可用的东西不要动。
- **不要围绕"等待批准"做界面**（D002）。用户全程完全访问模式，`PermissionRequest` 不会触发。
- **严守极简定位**（D005）。**不做**：多 agent 广度、终端精准跳转、用量额度面板、刘海 UI、手机推送。
- **不复制 `Octane0411/open-vibe-island` 的代码**。它是 GPL v3，复制会让本项目被迫 GPL 化。读思路可以，实现必须自有。
- 不装第三方依赖。改用户配置前照旧备份到 `~/.agentbell/backups/<时间戳>/`。
- 仓库公开：不写入绝对家目录路径、token 或无关个人信息。

## 完成条件

1. 菜单栏图标常驻，点开能看到运行中与最近完成。
2. 新开一个 Claude 桌面端会话跑一轮，菜单栏能反映"运行中 → 完成"，**且运行期间不会在几秒后被误判为结束**。
3. Codex 跑一次任务，菜单栏同样能反映"运行中 → 完成"。
4. 开机自启：能验证就验证，不能就写清楚如何验证。
5. `uninstall.sh` 能完整卸掉 App、LaunchAgent 与本轮新增的 hooks 并还原配置。**实际执行一次验证，再重新安装。**
6. **回归**：跑一次 Codex 任务确认仍有提示音，且 Computer Use 行为未变。
