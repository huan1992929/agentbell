# 任务：AgentBell 阶段 1 — 建公开仓库 + 事件提醒最小可用版

**目标**：用户在 Codex CLI 跑完任务、或 Claude 桌面端跑完一轮时，能立刻听到可区分的提示音并看到系统通知。装好即可用，随时可一键还原。

**范围**

1. 在 GitHub 建**公开**仓库 `agentbell`（账号 `huan1992929`，`gh` 已登录且有 `repo` 权限），把当前目录推上去。补 `README.md` 和 `.gitignore`（至少排除 `logs/`、`*.log`、`.DS_Store`）。
2. 实现 `bin/agentbell-event`、`bin/agentbell-codex-notify`、`install.sh`、`uninstall.sh`，行为严格按 `needs/设计说明.md` 第五至七节。
3. 跑 `install.sh` 完成实际安装，包括清理 Vibe Island 残留（用户已授权）。

**必要约束**

- 事件脚本在 agent 关键路径上，必须毫秒级返回，结尾 `exit 0`，不做网络请求、不等待子进程。
- 不能破坏 Codex Computer Use：`~/.codex/config.toml` 的 `notify` 只能串联，原样转发参数。
- 只挂 `Stop` / `Notification` / `PermissionRequest` 三个 hook，**绝不挂 PreToolUse / PostToolUse**。
- 改 `config.toml` 只做单行文本替换，不要重写整个 TOML（会丢注释和用户的项目信任配置）。
- 只用系统自带的 `sh` / `python3` / `osascript` / `afplay`，不装任何第三方依赖。
- 改配置前必须备份到 `~/.agentbell/backups/<时间戳>/`。
- 仓库是公开的：不要把 token、密钥或与本项目无关的个人信息写进去。

**完成条件**

1. 公开仓库已建并推送成功，给出仓库地址。
2. `install.sh` 跑通，打印出改了哪些文件、备份在哪。
3. 触发一次 Codex 任务完成，能听到提示音，且 Codex Computer Use 行为不变。
4. `~/.agentbell/logs/events.jsonl` 里能看到原始事件负载。
5. `uninstall.sh` 能把两份配置完整还原（请实际验证一次：还原后确认 `settings.json` 与 `config.toml` 和备份一致，再重新 `install.sh`）。

Claude 桌面端那一侧**留给人工确认**——桌面端是否真的触发 `~/.claude/settings.json` 的 hooks 尚未证实，是本项目最大未知。装好后日志里如果始终没有 `claude` 来源的记录，如实说明，不要自行改成轮询方案。

**不要做**：单元测试框架、CI、全量回归、菜单栏（阶段 2）、手机推送。

**参考**：`needs/设计说明.md`（架构与实现细节）、`needs/PROJECT_CONTEXT.md`（环境事实与历史包袱）、`needs/当前需求.md`（阶段划分与风险）。
