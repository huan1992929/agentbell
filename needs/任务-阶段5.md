# 任务：AgentBell 阶段 5 — 用量额度 + 灵动岛信息呈现打磨

执行前先读 `needs/decisions.md`，**D008 是本轮核心依据**。

## 一、用量额度（只做 Codex）

**Codex（做）**：数据在 rollout 文件里，`CodexActivity` 已经在读这些文件，数据源现成。已核实的结构：

```json
"rate_limits": {
  "primary": { "used_percent": 11.0, "window_minutes": 10080, "resets_at": 1790832478 },
  "secondary": null,
  "plan_type": "pro",
  "credits": { "has_credits": false, "unlimited": false, "balance": "0" }
}
```

- `window_minutes` 决定窗口名称（10080 = 7 天；如出现 300 则是 5 小时），**不要写死**，按实际值换算。
- `resets_at` 是 epoch 秒，显示为相对时间（"3 天后重置"）。
- `primary` 和 `secondary` 都可能存在，都要显示；为 null 就跳过。
- 取**最新一次**出现的 rate_limits（它随每轮刷新）。

**Claude（不做，且必须明说）**：本地没有账号级配额数据。`~/.claude/cache` 只有 `model-catalog`；会话 JSONL 只有每条消息的 `input_tokens` / `output_tokens`。

> **硬要求：不得用 token 累加估算冒充配额。** 那不是账号级数据。显示为"不可用"或干脆不显示 Claude 这一项，二选一，但不许编。

**位置**：灵动岛展开态的底部，一行足够，不要做成独立面板。

## 二、信息呈现打磨（四条）

### 1. 摘要改用任务标题，不用最后一条回复（本轮最重要）

现状是拿"最后一条助手回复"当摘要，结果大量条目没有信息量。实际出现过的例子：

```
disposition: ship
{"title":"查看 R22 法务红线启动提示词","description":"查看…
已对齐 `.darkAqua` 和导航问题提示保留 6 秒的最终源码。J…
```

看不出这条任务是干什么的。

**改为显示任务的开头（用户提交的提示词），不是结尾。** 数据来源：

- Codex：notify 负载里的 `input-messages`；rollout 里也有对应记录
- Claude：`UserPromptSubmit` hook 的提示词内容

取首行或首句，超长截断。**只读提示词本身，不要解析会话正文内容。**

### 2. 收起态要显示当前任务名与数量

现在收起态只有胶囊加活动指示，必须展开才知道在跑什么。灵动岛的价值恰恰是"不展开就能扫一眼"。收起态应显示：当前运行任务的简短标题 + 运行中数量。空间不够就只显示数量与一个来源图标，但不要什么都不显示。

### 3. 时间改成相对格式

- 完成条目：`09-25 17:34` → `27分钟前` / `1小时前`
- **运行中条目必须显示已运行时长**，现在只写"正在处理"，看不出跑了多久

### 4. 最近完成由 10 条减到 5 条

现在面板占大半屏高还带滚动条。配合相对时间后会明显变短。

## 必要约束

- **不要改通知与提示音的发送方式**（D001）。`bin/` 下三个脚本不许动。
- **不要动 `~/.codex/config.toml` 的 `notify` 串联**。
- **不要新增 `PreToolUse` / `PostToolUse`**。
- **视觉风格保持现在的标准 macOS 深色风**。不要模仿 Vibe Island 的像素字体 / 8-bit 风格——仓库是公开的，不做可辨识的复制品。
- **不复制 `Octane0411/open-vibe-island` 的代码**（GPL v3）。
- 不装第三方依赖，不用 SPM、不生成 Xcode 工程。
- 改用户配置前照旧备份。仓库公开：不写入绝对家目录路径、token、真实会话 ID 或会话正文。

## 完成条件

1. 展开态底部显示 Codex 用量：窗口名、已用百分比、重置时间。数值与 rollout 文件中最新的 `rate_limits` 一致（请实际比对一次）。
2. Claude 用量显示为不可用或不显示，**没有任何估算值**。
3. 最近完成的每条都能看出任务是什么，不再出现 `disposition: ship` 这类无信息摘要。
4. 收起态能看到运行中数量，有运行任务时能看到任务名。
5. 运行中条目显示已运行时长，完成条目显示相对时间。
6. 最近完成显示 5 条，面板高度明显下降。
7. **回归**：跑一次 Codex 任务、一次 Claude 桌面端会话，提示音仍在、运行状态仍正确、跳转仍可用。
