# 任务：AgentBell 阶段 3 — 灵动岛形态 + 点击直达会话

执行前先读 `needs/decisions.md`，**D006 是本轮的核心依据**，优先级高于其他文档。

## 目标

两件事：

1. 点击一个任务条目，**直接打开对应的会话界面**，不再弹独立窗口。
2. 把状态面板从菜单栏弹窗改成**灵动岛形态**：有刘海的屏幕贴刘海，没刘海的屏幕显示为顶部居中的浮动胶囊。

## 范围

### 一、点击直达

- **Claude 桌面端会话**：用 `claude://` 深链跳到具体会话。已确认存在 `claude://code/continue`、`claude://code/needs-input`、`claude://code/new` 三个路径，`sessionId` 是应用内高频参数名。**确切格式必须实测确认**——可以用我们日志里的真实 session_id 试，成功的判据是 Claude 前台切到那个会话，而不是只把 App 激活。
- **Codex 桌面版会话**：Open Island 文档称 `codex://threads/<id>` 可打开指定会话，**同样需实测**。
- **终端里的 Codex CLI 会话**：按 D005/D006，**不做终端 tab/split 精准定位**，最多激活终端 App 即可。
- 实测不通时的退路：激活对应 App 并如实说明无法定位到具体会话，**不要伪装成成功**。

### 二、灵动岛形态

- **有刘海的屏幕**：面板贴合刘海区域。内建屏实测刘海 185×32pt，`safeAreaInsets.top = 32`，`auxiliaryTopLeftArea` / `auxiliaryTopRightArea` 可用于定位。
- **无刘海的屏幕**：退化成**顶部居中的浮动胶囊**，宽度自适应内容。用户主屏是 LG HDR 4K（2560×1440，无刘海），**这是最常用的显示路径，必须做好，不能当成兜底敷衍**。
- **显示在哪块屏**：出现在当前鼠标所在的屏幕。切屏时跟随。
- **交互**：平时收起为最小态（有任务在跑时显示一个活动指示），悬停或点击展开显示完整列表。展开态里点条目触发上面的跳转。
- **窗口实现**：无边框、不抢焦点的 `NSPanel`（`.nonactivatingPanel`），层级在菜单栏之上，不进入 Mission Control 的窗口列表，不出现在 Dock 和 `Cmd+Tab`。
- **菜单栏图标保留**，作为兜底入口和退出入口。灵动岛是主界面，菜单栏不再承担完整列表。

## 必要约束

- **不要改通知与提示音的发送方式**（D001）。通知仍由 `bin/` 下的事件脚本发出，App 不发通知不播声音。阶段 1、2 已验证的东西不要动。
- **不要动 `~/.codex/config.toml` 的 `notify` 串联**，Codex Computer Use 依赖它。
- **不要新增 `PreToolUse` / `PostToolUse`**，Claude 和 Codex 两边都不要。
- **不复制 `Octane0411/open-vibe-island` 的代码**，它是 GPL v3。读思路可以，实现必须自有。视觉上也不要做成 Vibe Island 的逐像素复制品——本仓库是公开的。
- 不装第三方依赖，不生成 Xcode 工程，不用 SPM。机器上只有 Command Line Tools。
- 改用户配置前照旧备份到 `~/.agentbell/backups/<时间戳>/`。
- 仓库公开：不写入绝对家目录路径、token 或无关个人信息。

## 完成条件

1. **无刘海的外接屏上**，顶部居中胶囊正常显示，最小态与展开态切换正常。
2. **内建屏上**贴合刘海显示，位置不遮挡菜单栏图标和系统状态项。
3. 鼠标移到另一块屏，面板跟随出现在该屏。
4. 点击一条 Claude 桌面端会话，**Claude 前台切到那个会话**（做不到就如实说明，退化为激活 App）。
5. 点击一条 Codex 桌面版会话，同上。
6. 面板不抢焦点：展开和点击的过程中，当前正在输入的窗口不失去焦点。
7. **回归**：跑一次 Codex 任务和一次 Claude 桌面端会话，提示音仍在、运行状态仍正确、Computer Use 行为未变。
8. `uninstall.sh` 能完整卸载并还原，**实际验证一次再重装**。

## 不要做

单元测试框架、CI、全量回归、把通知迁进 App、终端 tab 级跳转、用量面板、手机推送。
